# Tasks: m2-sandbox-lifecycle-resume

A task is done when its listed scenario IDs have a passing subtest named exactly the ID on the public path and its `verify:` command is green. The fake `Sandbox` records `Open`, `Exec`, `Snapshot` and `Close`; the fake snapshot backend outlives a handle close so a recorded snapshot is still readable afterwards. The fakes live in `_test.go` files and are never exported. No test reaches a container or a network. The `PerCall` path and the governance behavior are unchanged: `sandbox.per-call-closes` and the other governance ids stay green under their own owners.

Lane acceptance is the owned scenario ids below plus the M1 regression floor plus the checks for each touched module. The global `task spec:gate GATE=M2` is a milestone gate, not a per-lane green gate; the adapter, egress and exec-timeout ids stay open under `m2-docker-sandbox`, `m2-e2b-sandbox` and `m2-sandbox-adapter-conformance`. A scenario run that matches zero tests does not count as acceptance.
