# Tasks: m2-sandbox-governance

A task is done when its listed scenario IDs have a passing subtest named exactly the ID on the public path, its `verify:` command is green, and `task lint` and `task test` are green for what it touched. The fake `Sandbox`, the fake `SecretResolver` and the fake workspace with and without `WorkspaceLister` live in `_test.go` files and are never exported; no test reaches a network or a container.
