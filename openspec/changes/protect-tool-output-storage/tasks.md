# Tasks

Every owned scenario id below names one exact subtest. Each task lists the ids it owns. Lane acceptance is the nine owned ids across `std/sandbox`, `std/outputs`, `std/tool/exec` and the `web_fetch` public path. The milestone regression floor is M1. Global M2 is a milestone gate and does not block this lane.

Apply order note: the `std/tool/http/fetch.go` edits come after the `Fetch` option edit, because the option type and the body-cap call are the same file. This is a sequencing rule only. The `fetch.go` edits share one dependency inside this change package: the cap-and-store step from task 1.1. `std/tool/http` imports `std/outputs`, not the reverse, and no task blocks on one outside this package.

Driver ownership: tasks 5.2, 5.3, 6.1, 6.2 and 6.3 are driver-owned. They touch the main specs, the scenario registry, the ADR set, the generated types index and the project-wide gates, which this lane does not edit. Implementation tasks are not marked complete during artifact remediation.
