| Align Docker link-local filtering under `AllowPrivate` | `adapter/docker/egress.go:120-123,139-140` includes `169.254.0.0/16` in `privateCIDRs` and emits an unconditional ACCEPT for that range under `AllowPrivate`, while `deniedAddress` at `adapter/docker/egress.go:195-202` denies link-local unicast and multicast in both modes; netfilter therefore permits more than the mirrored policy layer, so a non-HTTP client in an `AllowPrivate` workspace can reach link-local endpoints such as cloud metadata; the resolver ACCEPT rules added for allowlisted egress are equally unconditional on destination, so a link-local resolver on port 53 is reachable in both modes; pre-existing and deliberately outside the Docker egress repair that landed | `adapter/docker` egress / private-range policy |
