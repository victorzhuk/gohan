## 14. Evidence behind v0.3–v0.6 additions

| Addition | Published incident / finding |
|---|---|
| Intent-level keys, `Unknown` outcome, no transparent retries on writes | LIMBO benchmark: late commits duplicate in 56 % of episodes, redelivery 74 % without keys, 4 % with harness-attached keys; SDK retries cut exactly-once from 72 % to 50 %; agents reported success in 90 % of duplicate episodes |
| `Runs` lease + stateless recovery | Anthropic Managed Agents: stateless harness, durable session log, `wake(sessionId)`; "restart from zero" listed as a top-4 harness failure point |
| `iter.Seq2[T, error]` kept, error-tuple protocol, `Collect`/`Last`/`Drain`, no `iter.Pull` on the request path (ADR-0108) | Iterator-over-channel argument for LLM streams (the wire is a sequence; ADK-Go wraps SSE with range-over-func); community critique of `Seq2[T, error]` (two iterator species, pre-flight and cleanup errors, partial consumption) and the error-callback alternative; `iter.Pull` coroutine cost |
| Core budget rule, `Verify`, milestone order, capability freeze (ADR-0098) | "A model holds no credential, it produces text that something else decides to act on"; "the model can report an outcome that never happened" — verify by reading authoritative state; build order proof → identity → verification → scaffold; frameworks ≠ harnesses (capability without permission or proof structures); minimalist-harness papers and comparisons flag abstraction bloat |
| `taint`: `Capabilities{Exfil, PrivateRead}`, deterministic substring taint, `TaintPolicy` in the gate, trifecta check at `Build`, `Quarantine` keeps origins (ADR-0097) | Lethal trifecta (private data + untrusted content + external channel; remove one leg and exfiltration is impossible); CaMeL: provenance-tagged values blocked from sensitive tool arguments, control flow fixed before untrusted data, ~2.7× token cost; dual-LLM quarantine with structured hand-off; detection filters ~67 % on AgentDojo and 0 % on some models; "boundary collapse" when hand-offs degrade to strings; "a security property instead of a detection rate" |
| `release`: `Shadow` run mode with journal-answered side effects, `ReleaseManifest`/`ReleaseID` + `Variant` on runs, delta gating bands, judge ×3 median, incident import, online sampler (ADR-0096) | 2026 CI/CD-for-agents guidance: delta gating vs baseline (hard block −0.05, review −0.02), judge ×3 median with 0.10 spread flag at T=0, SHA-pinned datasets (60/25/15 prod/edge/failure), one regression case per incident, dated model versions + prompt SBOM + judge fingerprints, canary 1/5/25/100 % with online eval on ~10 % and rollback on judge drop, guard trips ×2, latency ×1.3, cost ×1.2; shadow-deployment posts return only the champion but leave challenger side effects unaddressed and note aggregate comparison is dominated by variance at small samples — pairwise replay preferred |
| `agui`: `Message.ID`, `ReasoningDelta`, typed shared state with RFC 6902 patches, `adapter/agui` mapping, frontend tools as `AwaitingTool` (ADR-0095) | AG-UI event catalog: run lifecycle with `parentRunId`, `RUN_FINISHED{outcome: interrupt}`, text/reasoning/tool streams keyed by ids in one namespace, `STATE_SNAPSHOT`/`STATE_DELTA` (JSON Patch), subagent events with `subagentRunId`, `REASONING_ENCRYPTED_VALUE`, metadata last-write-wins; integrations across LangGraph, Mastra, OpenAI Agents, ADK; "active, emerging" standard |
| `skills`: `SkillSource`, L1 catalog in prefix, `load_skill`/`read_skill_resource` meta-tools, untrusted = instructions-only, scripts only via sandbox, hash pinned (ADR-0094) | Agent Skills survey: three-tier progressive disclosure (metadata always, body on trigger, resources on demand); 26.1 % of 31,132 community skills vulnerable, script-bundling skills 2.12× more likely, 5.2 % high-severity, exfiltration 13.3 %, privilege escalation 11.8 %, one actor behind 54 % of confirmed malicious cases; proposed trust tiers T1–T4 with scripts only at T3+ and permission-manifest validation |
| `sandbox`: port + policy, deny-all egress, harness-injected secrets, per-session workspace snapshotted into checkpoints, sandbox seconds as a budget (ADR-0093) | 2026 sandboxing guides: microVM/gVisor/Kata behind container APIs, ~125 ms Firecracker boot but CNI setup +263 % under concurrency, warm pools as an economics problem, per-second billing accumulating in long sessions, deny-all egress with allowlists and restricted DNS, secrets as the top-cited risk ("the agent becomes your infrastructure"), gVisor syscall gaps |
| `interop`: `AwaitingInput`, MRTR → suspension, Tasks → `AwaitingTool`, catalog TTL → manifest refresh, annotations never raise effect (ADR-0092) | MCP 2026-07-28: stateless core (no `initialize`, no session header, `Mcp-Method`/`Mcp-Name` headers), MRTR `input_required` + `inputResponses` replacing server-initiated elicitation/sampling, Tasks extension (`tasks/get`, `tasks/update`, `subscriptions/listen`), `ttlMs`/`cacheScope` on list responses, roots/sampling/logging and HTTP+SSE deprecated; "MCP cannot enforce consent at the protocol level" — the host decides |
| `subflows`: isolation, typed `In`/`Out`, `MaxDepth` 2, `MaxParallelChildren` 8, mandatory child wall clock, `FailFast|Collect`, nested suspension (ADR-0091) | Field reports: fan-out breaks past ~12 workers and pipelines past 4–5 stages; structured outputs over prose; "a sub-agent without a timeout is a resource leak"; recursion capped at 1–2 levels; batch fan-out of ~8; approval propagation into children unaddressed anywhere in published harness guides |
| `context`: persisted `Compaction`, `ClearToolResults`, opaque-vs-text capability (ADR-0090) | Anthropic context editing (`clear_tool_uses`: keep-last-N, exclude tools, clear_at_least, `tool_use` retained; `compact`: summary block, custom instructions replace default, atomic transcript replacement, cache prefix invalidated) and OpenAI compaction (`/responses/compact`, opaque encrypted item, pass as-is, never prune, ZDR with `store=false`); Arize on subagent isolation and per-read caps |
| Fingerprint-based loop detection, `Notes`, output store | Compaction traps: infinite retries, redundant work and constraint amnesia after compaction; mitigations: external attempt log, sticky slots, structured checkpoints, output references |
| Hard `RunLimits` with soft warning | $800 in 40 minutes from an unbounded retry loop with only a soft alert |
| Error classification, args validation, unknown-tool rejection | Silent tool failures (81 % → 94 % completion after classification); tool and argument hallucination in failure catalogs |
| `Origin`, context guards, fencing | OWASP Agentic Top 10 2026: ASI01 goal hijack, ASI06 memory/context poisoning; prompt injection reported as the leading agentic failure class in production |
| Tool policy, description guard, pinned manifest | MCP tool poisoning (MCPTox: 36.5 % average compliance with poisoned descriptions); rug-pull CVE-2025-54136 (approval bound to name, not content) |
| Run trees | Hub-and-spoke orchestration as the surviving multi-agent pattern at ~15× token cost; relay-stage degradation of prose vs structured handoffs |
| Cancel shield, `Seq`, `EventLog`, `Detached` | Resume-token/Last-Event-ID analyses; multiple open SSE-reconnect bugs in agent frameworks with no event IDs |
| Core/std split, chain-as-data, `PromptSet`, `Explain`, `StepError` | Framework-exit retrospectives: "three classes and four function calls" for a one-call task; as much time debugging the framework as building; hidden prompts; huge stack traces through framework internals; no way to observe state or change tools dynamically |
