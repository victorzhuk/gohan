# ADR-0024: Strategies only where gohan ships ≥ 2 implementations; resolution: flow > profile > default from caps

Status: accepted · Origin: gohan-spec v0.13 decision D24

## Decision

Strategies only where gohan ships ≥ 2 implementations; resolution: flow > profile > default from caps.

## Context and evidence

Flexibility without a plugin zoo.

See `docs/design/evidence.md` for the published sources behind this decision.

## Consequences

Binding on the capability specs under `openspec/specs/`; changes require a new ADR that supersedes this one.
