# ADR-0010: Hooks attach to components (Model/Tool decorators), not runtime middleware

Status: accepted · Origin: gohan-spec v0.13 decision D10

## Decision

Hooks attach to components (Model/Tool decorators), not runtime middleware.

## Context and evidence

Governance survives graphs and workflow agents.

See `docs/design/evidence.md` for the published sources behind this decision.

## Consequences

Binding on the capability specs under `openspec/specs/`; changes require a new ADR that supersedes this one.
